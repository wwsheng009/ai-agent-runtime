    aicli micro web client

    aicli 本地会话的浏览器端微型客户端：仅监听回环地址，与终端 TUI 共享同一会话与渲染器状态。

    状态文档
    「调试」页签展示的内容与 aicli /debug 命令一致（GET /web/api/status?format=text）。
    页签
    对话 / 技能 / MCP / 日志 / 配置 / 缓存 / 分析（含路由观测） / 调试 / 关于
    当前会话
    （未选择会话）

    当前会话 ID（GET /web/api/sessions 的 current_session_id， 与终端 TUI 共享同一会话）：切换 / 新建 / 恢复会话后自动更新； 终端 TUI 内可用 /resume <会话 ID> 回到该会话， 脚本可用 aicli exec resume <会话 ID>。

    写令牌
    （未注入） /web/api/token

    状态变更请求（POST/PUT/PATCH/DELETE）需携带 X-AICLI-Token: <令牌> 或 ?token=<令牌>；令牌每进程随机生成、重启即轮换， 仅本机回环同源可读（页面已自动注入，手工调用脚本可读该端点或启动行）。 本地开发时回环地址（127.0.0.1/localhost）自动跳过令牌校验， 监听在 0.0.0.0 时回环 IP 始终免令牌，本地网络 IP 与远程 IP 需令牌。

    网格（aicli-mesh）
    加载中…

    多进程网格的只读视图（GET /web/api/mesh/self + GET /web/api/mesh/peers）：节点 ID / 网格根 / 节点计数（live / stale / conflict）。 治理动作（aicli-mesh gc / stop / spawn）留在 CLI， 本页不提供按钮，避免误点（网格 §5.8）。令牌默认脱敏。

    远程调用端点
    加载中…

    清单来自服务端 GET /debug/endpoints?format=json（与 aicli /debug 一致）； 标记 需令牌 的写操作要求 X-AICLI-Token， 令牌已由本页面自动注入，手工调用时见启动行。

    调试速览
    排查：GET /debug/chat/status（渲染状态）、 GET /web/api/screen?view=tui&tail=N（屏幕内容）、 /debug/pprof/（性能）； 驱动：POST /web/api/invoke（注入 prompt 并等 turn 结束，只等不注入加 wait_only）； 写操作需 X-AICLI-Token；完整清单见上方「远程调用端点」， 纯文本速览另见 /debug/endpoints?format=text 末尾「Debug 使用说明」。
