全局策略

对所有节点、所有通道生效。Bot 目标与会话级覆盖都只能在此基础上进一步收窄（取交集），不能放宽。

总开关与范围

控制哪些注意力会触发通知、后台推送走哪些通道，以及桌面 App 是否弹出。策略保存在网关、保存后立即生效；原生通知仍受系统通知权限与侧边栏的本机开关约束。

哪些消息触发通知

所有通道共用的事件总闸。下面的 Bot 目标只能在这里允许的事件里再挑子集。

已完成通知内容

「已完成」默认只报谁完成了。打开后会把该会话最后一条助手回复一并带上，方便在手机锁屏或 IM 里直接读结论；带了内容的那条通知会逐条投递、不参与合并（合并通知只保留标题）。

附带内容

最后一条不是助手消息时（例如等待用户输入）自动省略。

按字符截断（中文按 1 个字符算），超出部分以「…」结尾；各通道仍各有自己的长度上限。

通道

未配置的通道不可用；关闭通道只影响网关外发（Web Push / ntfy / AppPush），桌面 App 的本机弹窗受上方总开关与 kind 开关控制。

Bot 目标

每个 IM 群/私聊单独配置收件范围。这里的事件类型是「该目标自己的」收件范围，与上方全局「哪些消息触发通知」取交集。

已配置目标

把待审批 / 待回答 / 出错等通知直接发到 IM 群或私聊。QQ/微信推荐在「连接器」页把节点 bot 复制为网关 outbound-only 副本；「节点 Bot（委托）」保留为兼容旧部署，通知仍依赖节点在线与策略。
