# Tool selection notes for the full profile.
# This profile restores every tool; the notes below only restate the default
# preferences — nothing here narrows the surface.

## General preference

Use the narrowest tool that answers the question: read tools (view/grep/glob)
before shell, targeted edits before batch rewrites. The full surface exists so
nothing is blocked, not so everything gets used.

## Control-plane tools

Plan mode (plan_enter/plan_exit/plan_review), background jobs (job_*),
subagent/team orchestration (subagent_*, team_*, spawn_subagents), and
todos/goal tools are all available for complex, multi-step work.
